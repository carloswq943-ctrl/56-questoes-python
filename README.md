# 56 questoes de Python

Solucoes simples para executar no VS Code, na mesma ordem do enunciado recebido.

## Como executar

1. Abra esta pasta no VS Code.
2. Instale o Python 3.
3. Abra o arquivo desejado, por exemplo `questao01.py`.
4. Execute pelo botao **Run Python File** ou pelo terminal:

```bash
python questao01.py
```

Os arquivos que pedem dados usam `input()` no terminal. Os exercicios com listas, tuplas, dicionarios e matrizes possuem valores de exemplo quando o enunciado nao especifica dados iniciais.
